# Working on Flipitty

Run `mise install`, then `mise exec -- npm ci`. The one done command is `mise exec -- npm run check` (types, tests, Contract lint, fallow health). Report missing checks. This MIT project runs from a checkout, without a build.

Read docs/contract.md and docs/method-adoption.md. Follow [Impatient Programming v2.0](https://github.com/ag0os/method-imp/tree/v2.0). Each active obligation uses `### ID Title`, then separate `Status: agreed` or `Status: discovered proposal`, `Kind: functional` (or `non-functional; budget: ... measured by ...`), `Statement:`, `Reason:` and `Proof: test 'ID' in test/name.test.ts.` lines. Proof tests are top-level `test('ID: description', () => { ... })` calls, with a nonempty body and no skip options. Retire as `### ID Retired YYYY-MM-DD, merged into OTHER-ID.` Never reuse ids.

For a feature, record the agreement and ids in the change record, add Contract and test first, run red and inspect it in a separate step before implementation, then green. Keep each raw run in a unique timestamped log with Node version; default location is ignored `.evidence/`. Include a short red excerpt (time, Node version, failing test and reason) in the change record, since raw logs are not committed. Summarize checks in docs/check-evidence.md. Record already-present behavior honestly. New commands change the CLI-2 test's established command boundary (including the list rejection): obtain the owner's acceptance and rewrite that pin in the same change.

For a production bug: missing obligation first, test red on unfixed code, fix, mutation, full checks. Use `mise exec -- npx --no-install fallow mutation --all --allow-side-effects --allow-dirty --format json` for a meaningful advisory source run, or scope with the fixed file path instead of --all. Filesystem side effects occur: use scratch fixtures. Subprocess CLI execution is not attributed to mutation coverage; use its red regression test. Complete merge-base mutation is missing.

Use `fix:` only for live production defects, naming obligation and defect; otherwise `refine:`. Present proposals and gaps; green grants no merge authority. Unagreed established-obligation changes need owner acceptance. Proposed integration limit: one day or shorter agreement period; owner wait exempt, update base before resuming. Exhale removes dead code and needless copies, reads the whole Contract against the agreement, and obtains an independent read or names that gap.
